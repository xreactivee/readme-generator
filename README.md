# readme-generator

readme-generator — a Next.js app that generates dynamic, embeddable GitHub stats cards for your profile README.

## Features
- Generate dynamic GitHub stats cards
- Embeddable output for profile READMEs
- Built with modern web technologies

## Tech Stack
- TypeScript
- Next.js
- React
- Tailwind CSS

## Installation
```bash
git clone https://github.com/xreactivee/readme-generator.git
cd readme-generator
npm install
```

## Usage
Run the development server:
```bash
npm run dev
```
